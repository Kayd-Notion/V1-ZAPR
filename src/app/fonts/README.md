# Fonts (self-hosted)

Served from this folder by `next/font/local` (see `src/app/layout.tsx`): no
request to Google Fonts or any other CDN. Latin subset, from the Fontsource
packages (v5.3.0). All three are under the SIL Open Font License 1.1 (see the
LICENSE files next to them).

| Role | Font | Files | Used for |
|---|---|---|---|
| Display | Chakra Petch 500/600/700 | `ChakraPetch-latin-*.woff2` | logo "ZAPR", titles, tabs, buttons, ranks |
| Body | Inter (variable 100–900) | `Inter-latin-var.woff2` | all running text |
| Mono | JetBrains Mono (variable 100–800) | `JetBrainsMono-latin-var.woff2` | SOL amounts, zap scores, wallet addresses |
